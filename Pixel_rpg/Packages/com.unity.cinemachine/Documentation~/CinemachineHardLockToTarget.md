# Hard Lock to Target

This CinemachineCamera **Position Control** behavior uses the same position at the **Tracking Target**. In other words, the target acts as a mounting point for the CinemachineCamera.

### Properties

| Property    | Description                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- |
| **Damping** | Adds lag to the camera's responsiveness. Value is the approximate time to catch up, in seconds. |
